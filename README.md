# Heba Ajjour

Cybersecurity Engineering student at UCAS, Gaza — specialising in applied cryptography and smart contract security.

Currently finishing **AdaptiveQKE**, a graduation project proposing a context-aware hybrid TLS 1.3 key exchange that combines ML-KEM and ECDH, evaluated across 1,800 controlled handshake measurements.
